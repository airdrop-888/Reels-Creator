ⓘ Panduan Cara Pakai & Catatan Sistem▾

1. Alur kerja: buka tab chat tujuan → simpan antrean prompt di popup ini → klik Suntik Prompt. Teks akan masuk ke kotak chat. Sejak v1.2.1, suntik juga otomatis menyimpan draf editor bila belum tersimpan.

2. Tab lain: bila memakai website AI berbeda, buka tab tersebut lalu klik Aktifkan di tab ini.

3. Prompt tersimpan: prompt yang sering dipakai ulang disimpan di pustaka di atas. Klik Muat untuk mengeditnya di editor, atau Pakai untuk langsung menjadikannya antrean.

4. Auto-batch: atur jeda tenang dan maks tunggu, klik Mulai auto-batch, lalu biarkan berjalan. Batch dijeda otomatis kalau jawaban belum selesai melewati maks tunggu, atau tombol kirim tidak ketemu — cek chat lalu tekan Lanjut. Satu batch per satu tab, jangan tutup tab selama batch jalan.

Catatan media: dialog file browser OS tidak dapat dipaksa otomatis oleh extension. Extension akan mencoba upload via input file, atau otomatis menyalin gambar ke clipboard (cukup tekan Ctrl+V pada kotak chat).
