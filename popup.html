🎬 Reels-Creator

Tempel antrean prompt pembuatan video di bawah, satu prompt dipisah baris ---. Bisa juga load file .txt / .json (array string, atau array objek dengan field prompt).

Dilampirkan bersama tiap prompt yang disuntik — misalnya foto karakter, gaya visual, atau produk yang jadi acuan video.

Cara pakai: buka chat di tab lain → simpan antrean di sini → klik Suntik prompt berikutnya (atau tombol yang sama di panel kecil pojok kanan bawah halaman chat). Teks masuk ke kotak chat, lalu kirim manual — kecuali auto-send ON. Untuk chat di luar daftar situs bawaan, buka tab chat itu dulu lalu klik Aktifkan di tab ini.

Catatan gambar: dialog file picker bawaan OS tidak bisa diisi otomatis oleh extension mana pun. Extension mencoba lewat input file chat dulu, kalau tidak bisa, gambar pertama disalin ke clipboard — tinggal Ctrl+V di kotak chat.
